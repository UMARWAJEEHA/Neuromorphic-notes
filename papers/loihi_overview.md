# Intel Loihi: Neuromorphic Computing Architecture

## Paper Reference
Intel Loihi Neuromorphic Research Chip (Overview Paper)

## Problem Addressed
Conventional AI hardware relies on clock-driven, power-hungry architectures that
struggle with energy efficiency and real-time adaptability.

## Architecture Overview
- Event-driven processing model
- Asynchronous computation
- Distributed memory near compute units
- On-chip learning support

## Key Hardware Concepts
- Spiking neurons implemented in silicon
- No global clock → reduced power consumption
- Parallel, scalable core design

## Why This Matters for AI Hardware
Loihi demonstrates how **electronics-level architectural choices** can significantly
improve power efficiency and enable real-time intelligent systems.

## Personal Takeaways
- Event-driven logic is central to energy efficiency
- Memory locality is critical in neuromorphic hardware
- Architecture matters more than raw model size

## Open Questions
- How scalable is this architecture for commercial systems?
- What are the trade-offs compared to GPU-based accelerators?
